# Hex Tunnel 1.0.0-rc.21

Fecha: 2026-08-05

## Corrección principal

La finalización AMD64 podía abortar por dos errores independientes:

```text
/etc/deekayvpn/slowdns_ns.txt: No such file or directory
module: unbound variable
```

El primer error ocurría porque `hextunnel-finalize-install` intentaba abrir archivos de estado opcionales aunque SlipStream no se hubiera solicitado. El segundo provenía de declarar `module` y un marcador derivado en la misma instrucción `local` bajo `set -u`.

## Cambios

- Los archivos `slipstream_domain.txt` y `slowdns_ns.txt` se leen únicamente cuando existen y son legibles.
- La ausencia de estado opcional produce una cadena vacía sin mensajes ni abortos.
- SlowDNS solo es obligatorio cuando existe un dominio SlipStream pendiente.
- `module_mark_installed` y `module_mark_uninstalled` inicializan primero el nombre del módulo y después construyen su marcador.
- Se añaden pruebas bajo `set -u` para ambos marcadores.
- Se añade una prueba que lee un archivo opcional inexistente y otro con CRLF.

## Recuperación

La activación existente se conserva. Después de publicar `1.0.0-rc.21`, la instalación puede reanudarse con el instalador comercial normal. No se deben crear manualmente archivos vacíos en `/etc/deekayvpn`.
